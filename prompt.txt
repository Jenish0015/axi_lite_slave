Complete the implementation of the AXI-Lite slave module in sources/axi_lite_slave.sv.

The module has 4 registers mapped as follows:
- 0x00: CTRL (write bit[0] = 1 to start computation)
- 0x04: DATA_IN (input value)
- 0x08: DATA_OUT (read-only result)
- 0x0C: STATUS (read-only, bit[0] = 1 when done)

When start is triggered, compute: ((DATA_IN ^ 0xA5A5A5A5) + DATA_IN) >> 2
