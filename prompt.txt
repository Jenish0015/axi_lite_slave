Implement the complete RTL in **`sources/axi_lite_slave_dut.sv`**.

Implement the AXI4-Lite slave as **`module axi_lite_slave`**. That file is what the automated cocotb build uses (`hdl_toplevel="axi_lite_slave"`).

**Note:** `sources/axi_lite_slave.sv` in this repository is a **separate SystemVerilog testbench** (`axi_lite_slave_tb`) for local bring-up; it is **not** the DUT file the pytest/cocotb runner compiles. Do not assume the DUT ports live there.

**Ports (must match):** `ACLK`, `ARESETn` (active-low async reset); full AXI4-Lite write (`AWADDR[31:0]`, `AWVALID`, `AWREADY`, `WDATA`, `WSTRB`, `WVALID`, `WREADY`, `BRESP`, `BVALID`, `BREADY`) and read (`ARADDR[31:0]`, `ARVALID`, `ARREADY`, `RDATA`, `RRESP`, `RVALID`, `RREADY`). Decode registers using **`addr[5:0]`** (aligned 32-bit addresses 0x00, 0x04, 0x08, 0x0C).

---

## Register map

| Address | Name      | Access | Description |
|---------|-----------|--------|-------------|
| 0x00    | CTRL      | Write (per-byte WSTRB) | **Byte 0:** if `WSTRB[0]=1` and `WDATA[0]=1`, **start** pipeline from current **DATA_IN**; if `WSTRB[0]=1` and `WDATA[0]=0`, **clear** pipeline. If `WSTRB[0]=0`, **no** start/clear (masked write). Other bytes: update CTRL storage per strobes if you implement read-back. |
| 0x04    | DATA_IN   | Write (per-byte WSTRB) | Merge `WDATA` into `DATA_IN` only on strobed bytes; others keep previous value. |
| 0x08    | DATA_OUT  | Read | While pipeline **busy**, return **0**. After run completes, return the **pipelined** result (see below). |
| 0x0C    | STATUS    | Read | **0** when idle/busy without completion bit set; **bit 0 = 1** when a run has **finished** (golden behavior). |

Hidden cocotb tests read **CTRL** after reset (expect **0**); implement read-back consistently if you expose CTRL on reads.

---

## Pipeline and arithmetic

- **`PIPE_CYCLES` = 32**: From **start** until **DATA_OUT** and **STATUS** reflect completion, **32 enabled clock edges** must elapse (see backpressure: cycles where the slave stalls on **R** or **B** must **not** count down).
- **Operand**: When a start is recognized, latch from the current **DATA_IN** register (post-merge).
- **Result** (32-bit wrap on XOR/add, then shift):

  `result = (((operand ^ 32'hA5A5A5A5) + operand) >> 2`

- **While busy**: **DATA_OUT** reads must be **0** (early-read checks).
- **Stall**: Typical `pipe_stall = (RVALID & ~RREADY) | (BVALID & ~BREADY)`; do not advance the pipeline counter while stalled.

---

## CTRL / reset

- **Clear** stops the pipeline and clears busy/done behavior per your FSM (golden clears STATUS on trigger and sets done at end).
- **ARESETn** low: cancel in-flight work; after release, **DATA_OUT**, **STATUS**, and **CTRL** read as **0** where tested; no stale completion from before reset.

---

## AXI4-Lite (strict)

1. **AW** and **W** decoupled (either order).
2. **BVALID** only after **both** AW and W handshakes for that transaction.
3. **RVALID** after AR handshake; **RDATA/RRESP** stable until **RREADY** completes.
4. **RREADY=0**: hold **RVALID** and data/resp for multiple cycles.
5. **BREADY=0**: hold **BVALID/BRESP**; keep **AWREADY=0** while a write response is pending (tested).
6. Partial **WSTRB** on **DATA_IN** required for byte-wise merge.

**Responses:** Hidden tests expect **OKAY** (`2'b00`) on successful mapped accesses. SLVERR on unmapped or illegal writes is **not** asserted by the hidden suite (your local TB may add it).

---

## Reference FSM shape (golden-style)

- **Write:** small FSM—capture **AW**, then accept **W**, then assert **BVALID** until **BREADY**. Only apply register writes on the **W** handshake using the latched address. **AWREADY** must respect pending **B**.
- **Read:** after **AR**, assert **RVALID** and hold until **RREADY**; **ARREADY** low while a read response is pending.

---

## Datapath (must match timing, not combinational)

- Do **not** update **DATA_OUT** with the final result on the same cycle as the CTRL start. Commit **DATA_OUT** (and set **STATUS** done) only after the **fixed delay** (32 non-stalled cycles) from start.
- **STATUS[0]** should reflect **done** after that delay; clearing via CTRL (byte0 strobe with 0) should align with golden expectations.

<HINTS>
Derived from common agent/debug traces (Icarus + decoupled AXI + cocotb-style checks).

 - **Icarus / Verilog TB:** ` @(posedge clk iff …) ` is **not** reliable in Icarus—use `wait(AWVALID & AWREADY)` / `wait(WVALID & WREADY)` / `wait(ARVALID & ARREADY)`, then **one** `@(posedge ACLK)` before deasserting `*VALID`. Wait on **both sides** of the handshake (`VALID & READY`), not `READY` alone, or the task can unblock before your beat started.

 - **Write FSM / `BVALID` oscillation:** If the master keeps `AWVALID`/`WVALID` high after the first beat, returning to `W_IDLE` while **clearing `BVALID` too early** or toggling state every cycle causes **IDLE↔RESP thrash** (`AWREADY`/`WREADY` flicker, no clean `B`). Keep **`BVALID` asserted and stable** until `BREADY` completes the response; only then drop `BVALID` and re-arm `AW`/`W` accepts. **`AWREADY` must stay 0** while any write response is outstanding.

 - **Register writes vs. `W_RESP`:** Applying CTRL/DATA_IN merges on **every** clock while `write_state==W_RESP` can re-fire pipeline/CTRL logic. Commit register updates **once per completed write** (e.g. a single cycle or tied to the same event that arms `B`, not an ungated multi-cycle `if` in RESP).

 - **Reads / `ARREADY` after `R`:** After `RVALID && RREADY`, `RVALID` should **clear**; hidden tests check that. If your **self-TB** asserts a **second** `ARVALID` while still expecting an “idle” `ARREADY==1`, the slave may **immediately accept** the next `AR` and drive `ARREADY` low again—that is **legal AXI**. Deassert `ARVALID` between reads when checking post-handshake `ARREADY`. Prefer **registered** `ARREADY` recovery (high on the `posedge` **after** `R` completes) for chunk-read torture.

 - **Pipeline / CTRL:** Count **32** steps only when **not** stalled: `(RVALID & ~RREADY) | (BVALID & ~BREADY)`. **Start:** CTRL byte0 strobed, `WDATA[0]` **0→1**, latch operand from **merged** `DATA_IN`. **Supersede while busy:** if byte0=1 is written again while **`ctrl` already 1** and the pipeline is **still running**, **reload** operand from current `DATA_IN` and **restart** the 32-count (do not keep the first operand).

 - **Golden `DATA_OUT` check:** The add is **32-bit unsigned wrap** before `>> 2`. In Python: `tmp = ((op ^ 0xA5A5A5A5) + op) & 0xFFFFFFFF; out = tmp >> 2`. A wrong hand sum often differs in the **middle nibbles** (e.g. `0x32711295` vs correct `0x32719295` for `op=0x12345678`).

 - **Baseline vs. grading:** An **empty `tests/`** tree on the baseline branch is normal; **cocotb** tests arrive via the **test patch** in grading—`pytest …test_axi_lite_slave_hidden…` may **not** exist until then.

</HINTS>
