Implement the AXI-Lite slave module in sources/axi_lite_slave.sv from scratch.
The module ports are already defined. You must fill in the complete RTL implementation.

## Register Map
| Address | Name     | Access | Description            |
|---------|----------|--------|------------------------|
| 0x00    | ctrl_reg | R/W    | bit[0] = start trigger |
| 0x04    | data_in  | R/W    | input data register    |
| 0x08    | data_out | RO     | computed result        |
| 0x0C    | status   | RO     | bit[0] = done flag     |

## AXI-Lite Write FSM (3 states: W_IDLE, W_DATA, W_RESP)
- W_IDLE: assert AWREADY=1, wait for AWVALID, latch address, go to W_DATA
- W_DATA: assert WREADY=1, wait for WVALID, write data to register, assert BVALID=1, go to W_RESP
- W_RESP: wait for BREADY=1, deassert BVALID, return to W_IDLE

## AXI-Lite Read FSM
- When ARVALID=1 and RVALID=0: latch address, assert ARREADY=1 and RVALID=1, output RDATA from register map
- When RREADY=1: deassert RVALID and ARREADY

## Datapath
- When ctrl_reg[0]=1: compute and store:
  data_out_reg = (((data_in_reg ^ 32'hA5A5A5A5) + data_in_reg) & 32'hFFFFFFFF) >> 2
- Set status_reg[0]=1 after computation
- Clear status_reg[0]=0 when ctrl_reg[0] is written to 0

## Reset (ARESETn=0 active low)
- All internal registers reset to 0
- All AXI outputs reset to 0
- FSM returns to W_IDLE
