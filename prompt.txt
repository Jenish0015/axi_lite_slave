Complete the implementation of the AXI-Lite slave module in sources/axi_lite_slave.sv.

The module has 4 registers:
- 0x00: CTRL (R/W) - bit[0] = start trigger
- 0x04: DATA_IN (R/W) - input value
- 0x08: DATA_OUT (RO) - computed result
- 0x0C: STATUS (RO) - bit[0] = done flag

When CTRL bit[0] goes from 0 to 1 (rising edge), compute and store in DATA_OUT:
  DATA_OUT = (((DATA_IN ^ 32'hA5A5A5A5) + DATA_IN) & 32'hFFFFFFFF) >> 2

After reset (ARESETn=0), all registers must be 0.
STATUS becomes 1 after computation completes, and clears back to 0 when CTRL bit[0] is written to 0.
